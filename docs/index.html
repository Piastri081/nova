Everything included

Built like a real streaming app.

No web wrapper. No placeholder screens. Every feature below ships in 1.0.0.

✉︎

Passwordless sign-in

Six-digit codes by email (Resend) or SMS (Twilio). Codes are hashed, single-use, and expire in ten minutes.

◉

Up to five profiles

Each profile keeps its own My List, Continue Watching, and playback position. Optional 4-digit PIN with server-side lockout.

☁︎

Hosted cloud

Accounts, profiles, lists, and progress live in a Cloudflare backend operated for Nova. Sign in on another iPhone or iPad and everything is already there.

▷

Continue Watching

Playback progress is saved while you watch and when you leave the player. Tap a card to resume exactly where you stopped.

✦

Liquid Glass

Native glassEffect surfaces on iOS 26+, with an automatic material fallback on iOS 17–25 and when built with Xcode 16.

▦

Home & Lock Screen widgets

Continue Watching and Trending widgets in small, medium, and large sizes, plus inline, circular, and rectangular Lock Screen families.

⌕

Search & discovery

Search by title, genre, or year. Curated rows for noir, sci-fi, horror, comedy, silent era, drama, family, and adventure.

⚖︎

Legal by design

Only Internet Archive public-domain and Creative Commons titles. Every detail page links back to the source and license.

Install

Download the unsigned IPA.

The GitHub Release contains Nova.ipa, built without a signing certificate. iOS will not install it by tapping the file. Use one of these tools:

  1. AltStore — add the IPA to My Apps and sign with your Apple ID.
  2. Sideloadly — drag the IPA in, enter your Apple ID, and install.
  3. Xcode — open the generated project, select your team, and run on your device.
The public build is preconfigured. Just install, enter your email or phone number, and use the 6-digit code. The hosted backend is operated for Nova. If you prefer to run your own server, the same Backend/ folder deploys to your Cloudflare account.

Hosted + open source

No server setup required.

The public Nova build talks to a Cloudflare Worker operated for the project. Accounts and profiles are stored in D1 with hashed tokens, so you never configure a server. The entire backend is open source, so developers can still deploy their own copy.

  • Hashed session tokens and login codes
  • Per-identifier and per-IP rate limits
  • Profile PINs with five-attempt lockout
  • Kids profiles filtered server-side
  • Resend for email, Twilio for SMS
